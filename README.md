# Rho Chapter Website - La Unidad Latina, Lambda Upsilon Lambda Fraternity, Inc.
This is the official repository for the Rho Chapter of La Unidad Latina, Lambda Upsilon Lambda Fraternity, Inc. It hosts an immersive 3D web experience designed to showcase the fraternity's legacy, history, and values. The website features custom Three.js models, dynamic GSAP ScrollTrigger animations, and responsive canvas rendering for an engaging user experience.

## Features
*   **Immersive 3D Experience:** Interactive 3D models of MacBooks and other elements create a visually rich and engaging user interface.
*   **Dynamic Animations:** GSAP ScrollTrigger is utilized extensively to create captivating animations that respond to user scrolling, bringing the content to life.
*   **Chapter Showcase:** Dedicated sections highlight the Rho Chapter's history, achievements, and its presence at Duke University.
*   **Interactive Product/Model Viewer:** Users can explore different aspects of the fraternity's identity through customizable 3D models, allowing them to change colors and sizes.
*   **Responsive Design:** The website is built with responsiveness in mind, ensuring a seamless experience across various devices and screen sizes.
*   **Contact Form:** An integrated form allows prospective members and interested parties to easily get in touch.
*   **Historical Information:** Key facts, mottos, colors, and the fraternity's mission statement are presented in an accessible and visually appealing manner.
*   **Navigation:** A persistent navigation bar allows for easy access to different sections of the website.

## Usage
To explore the Rho Chapter website:

1.  Navigate to the deployed website (link).
2.  Scroll through the page to experience the animated sections, 3D models, and historical information.
3.  Interact with the product viewer to explore different model configurations.
4.  Use the navigation bar to jump to specific sections.
5.  Utilize the contact form to send inquiries.

## Technologies Used
*   **React:** A JavaScript library for building user interfaces, used as the primary framework for the website's frontend.
*   **Three.js:** A JavaScript 3D library that enables the creation of animated 3D graphics in a web browser. Used for rendering and manipulating 3D models.
*   **@react-three/fiber:** A React renderer for Three.js, allowing Three.js to be used declaratively within React components.
*   **@react-three/drei:** A collection of useful helpers and abstractions for `@react-three/fiber`, simplifying common Three.js tasks like loading models, adding controls, and creating lights.
*   **GSAP (GreenSock Animation Platform):** A powerful JavaScript animation library used for creating complex, performant animations.
    *   **ScrollTrigger:** A GSAP plugin that makes it easy to trigger animations based on scroll position.
*   **Tailwind CSS:** A utility-first CSS framework for rapidly building custom designs. Used for styling all components and ensuring responsiveness.
*   **Vite:** A next-generation frontend tooling system that provides an extremely fast development server and optimized builds.
*   **Zustand:** A small, fast, and scalable bearbones state-management solution. Used for managing global state, such as the selected color and scale for the 3D models.
*   **React Responsive:** A utility for responsive design in React, allowing components to adapt to different screen sizes.
